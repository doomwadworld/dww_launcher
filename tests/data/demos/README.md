# Test demos

Real demo files used to test the `.lmp` parser.

- `dsda_*.lmp`: recorded with DSDA-Doom 0.27.5 on Freedoom: Phase 2 MAP01, UV, using
  `-complevel 2`, `-complevel 2 -longtics`, `-complevel 9`, `-complevel 21` and
  `-complevel 21 -dsdademo`.
- `freedoom*_DEMO*.lmp`: the DEMO lumps from Freedoom 0.13.0 (`freedoom1.wad`, `freedoom2.wad`).
  DEMO4 of Phase 1 is a 3-player co-op demo; DEMO3 of Phase 2 has a DSDA-Doom footer.
